 📂 Data Directory
This directory provides information about the datasets used in the GeoCover Rawalpindi: Sentinel-2 Land Cover Classification Using Random Forest project.

 🛰️ Datasets Used
1. Sentinel-2 Surface Reflectance Harmonized
- Provider: European Space Agency (ESA) / Copernicus
- Application: Satellite imagery for land-cover classification.
- Source: [Copernicus Data Space](https://dataspace.copernicus.eu/)

2. ESA WorldCover v200
- Provider: European Space Agency (ESA)
- Application: Reference land-cover labels for model training and evaluation.
- Source: [ESA WorldCover](https://worldcover2021.esa.int/)

3. Study Area Boundary
- Location: Rawalpindi District, Punjab, Pakistan
- Source: FAO GAUL administrative boundaries.
- Application: Defining the geographical extent of the classification.

📌 Data Availability
The original satellite imagery and reference datasets are accessible through their respective providers and Google Earth Engine.
This directory is retained for dataset documentation and source information.

⚠️ Note
The classification results are based on the selected satellite imagery, spectral features, and reference labels. Evaluation metrics should be interpreted as agreement with ESA WorldCover reference data rather than independent field-based validation.
